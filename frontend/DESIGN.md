# KnowGap 前端视觉规范

基于墨浅设计系统（Moqian）的 **Quiet Utility** 配置：这是一个学生反复使用的学习工具，任务优先，界面安静，强调色只出现在“老师的笔迹”和当前状态上。

## 核心想法：批注

诊断不做成仪表盘卡片，而是像老师批改作业：

- 学生的作答放在浅灰作答区里，**诊断依据在原文中划线**（后端契约保证 `evidence` 是学生原文中的一段）。
  - 疑似误区：强调色波浪线
  - 判断正确：绿色实线
  - 暂不确定：灰色点线
- 作答下方是一条**批注**：左侧 1px 强调色细线，写明结论、知识点、启发式置信度和依据。
- 后续每一轮学生回答都有自己的批注（紧凑样式）；导师回复是开放正文，不加底色。

## 令牌（`src/app/globals.css`）

| 角色 | 变量 | 值 |
| --- | --- | --- |
| 工作区底色 | `--bg` | `#ffffff` |
| 侧栏底色 | `--surface-side` | `#f6f6f6` |
| 选中行 / 作答区 | `--surface-soft` | `#f0f0f0` |
| 正文 / 强调正文 | `--ink` / `--ink-strong` | `#292929` / `#141414` |
| 次要 / 元信息 | `--ink-muted` / `--ink-dim` | `#555555` / `#6b6b6b` |
| 分隔线 / 控件边界 | `--rule` / `--rule-strong` | `#dedede` / `#767676` |
| 强调色 | `--accent` / `--accent-soft` / `--accent-ink` | `#c84b1e` / `#fbece5` / `#a33c15` |
| 错误 | `--danger` / `--danger-surface` | `#a61b1b` / `#fdeeee` |
| 记忆状态 | `--st-suspected` 等 4 个 | 琥珀 / 砖红 / 蓝 / 绿 |

换强调色只需改 `--accent` 三个变量。浅灰侧栏上的小号强调文字用 `--accent-ink`，保证对比度不低于 4.5:1。

## 强调色只用在这些地方

批注标记与依据下划线、当前步骤、导师名、本轮参考的记忆（浅强调底）、Mock 标记、输入框聚焦、焦点环。**按钮不用强调色**：主按钮是实心深墨，次按钮是描边，第三级是文字按钮。

## 字体

| 角色 | 变量 | 用在哪里 |
| --- | --- | --- |
| 内容 | `--font-content`（华文中宋 → Noto Serif SC → 宋体） | 题目、作答、导师回复、批语、记忆摘要、栏目标题 |
| 界面 | `--font-ui`（微软雅黑 UI → 苹方 → Noto Sans SC） | 按钮、标签、元信息、数字 |
| 等宽 | `--font-mono` | 序列、代码片段、会话 ID |

只是回退栈，不下载字体。标题用常规字重（400），层级靠字号与留白；数字统一 `tabular-nums`。

## 结构与组件约定

- **分区靠明度和细线，不靠卡片**：三栏之间 1px 分隔线，列表项之间细线，不加阴影。只有浮层（Mock 控制台、通知）用边框 + 浮起阴影。
- **圆角**：控件 6px，小标记 3px，结构区域方角。
- **状态标记**：7px 色块 + 文字，从不只靠颜色；“待确认”是空心色块，表示证据还不充分。
- **置信度**：只显示数值和“启发式置信度”说明，不画进度条，避免被读成准确率或掌握率。
- **编号**：只给真实的先后顺序编号（学习闭环四步、证据先后）；题目列表不编号。
- **动效**：180ms 颜色过渡，新内容 300–400ms 淡入上移，等待用一条细线推进；尊重 `prefers-reduced-motion`。
- **触屏**：粗指针设备上按钮最小 44px。

## 断点

≥1241px 三栏；901–1240px 两栏（学习记忆移到工作区下方）；≤900px 单栏。手机宽度下说话人标签移到内容上方，页头只保留“知隙”、Mock 标记和图标按钮。
