# KnowGap 前端视觉规范

紧凑的工具界面，参考 Linear 的信息密度与交互：中性灰阶 + 一个克制的蓝色强调；浅色 / 深色两套主题，默认跟随系统，侧栏左上角可手动切换（跟随系统 → 浅色 → 深色，保存在本机）。

## 布局

桌面应用式外壳，三栏各自滚动：

| 区域 | 内容 |
| --- | --- |
| 侧栏 `Sidebar` | 品牌与主题切换、「新会话」（快捷键 `N`）、数据来源（Mock 控制台 / 后端状态）、题目导航（右侧数字 = 该知识点的学习记忆数）、演示身份 |
| 主区域 | 顶栏：面包屑 + 学习闭环进度；内容区：题目 → 作答 / 诊断与引导；底部固定输入框（快捷键 `/` 聚焦） |
| 学习记忆 | 紧凑记录行：状态图标 + 摘要，点击展开证据，悬停出现删除 |

主画布贴边铺满，不设外边距、外围描边、圆角或内高光；侧栏用底色区分，不额外画外框。输入框、弹窗和有交互含义的局部边界保留。Electron 主窗口使用 36px 隐藏式标题栏，与主画布同色，保留原生窗口按钮和拖拽、双击最大化、缩放能力；浏览器和快问浮窗不预留这段高度。断点：≥1241px 标准宽度；901–1240px 收窄侧栏与记忆栏；≤900px 单栏堆叠，顶栏与输入框吸附。

## 核心交互：诊断批注

- 作答放在带边框的作答框里，**诊断依据在原文中标出**（后端契约保证 `evidence` 是学生原文中的一段）：疑似误区 = 橙色衬底 + 波浪线，判断正确 = 绿色衬底 + 实线，暂不确定 = 灰色点线。
- 作答下方挂一块批注面板：结论（图标 + 文字）、知识点、启发式置信度、依据说明。
- 后续每轮学生回答都有紧凑批注；导师回复是普通正文。对话按活动流排列（头像沿细竖线）。
- 本轮送入上下文的历史记忆在对话上方用浅蓝框列出，点击跳到右侧对应记录并展开证据。

## 强调色只用在这些地方

主按钮、当前步骤、当前题目图标、导师头像、本轮参考的记忆、焦点环与输入框聚焦。其余一律中性灰。Mock 相关提示用橙色，表示“这是模拟数据”。

## 字体与字号

全部无衬线：`Inter Variable`（本地依赖 `@fontsource-variable/inter`，不走外网）+ 苹方 / 微软雅黑 UI 作为中文回退。字号 11.5 / 12.5 / 13.5（界面）/ 15 / 18 / 22px；对话正文与用户气泡用 `--text-read`（15px，行高 1.75，最大约 68 字符宽），表格只留横向分隔线；数字统一 `tabular-nums`。

## 组件约定

- **按钮**：实心蓝（主）、描边（次）、文字（第三级）；高度 28 / 32 / 36px，粗指针设备 ≥ 40px；按下时轻微缩放。
- **记忆状态图标**（`StatusIcon`）：待确认 = 虚线圆、需要巩固 = 圆内感叹号、改善中 = 半填充、已解决 = 实心勾。形状本身区分状态，颜色只是加强。
- **置信度**：只显示数值与“启发式置信度”说明，不画进度条。
- **浮层**（Mock 控制台、通知）：`--shadow-popover`，用 `position: fixed` 避免被滚动容器裁切。
- **动效**：悬停 120ms、状态 180ms，新内容 220–260ms 淡入上移 3–4px，等待用一条推进的细线；主题切换时颜色 220ms 过渡。尊重 `prefers-reduced-motion`。
- **桌面启动**：启动主窗口立即展示同底色品牌层，复用原标志的五个切面，在约 750ms 内由分离到聚合、名称淡入；只覆盖真实的本地服务与页面加载时间，不设置最低展示时长或假进度。页面载入后 220ms 交叉淡出并销毁临时渲染层，托盘唤醒不重播。跟随上次主题；系统减弱动态效果时直接显示静态标志，仅保留 80ms 退出淡化。后台启动不弹窗口，隐藏时暂停动效。
