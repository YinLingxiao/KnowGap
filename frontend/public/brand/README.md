# KnowGap — 02B

Approved identity: two softly curved book pages separated by negative space,
paired with the selected B / Soft Serif lettering. Neutral monochrome only.

- `knowgap-logo.svg`: book symbol; two paths, inherits `currentColor` when inline.
- `knowgap-wordmark.svg`: approved custom lettering converted to vector outlines.
  This is a fixed wordmark, not an installable font or a claim to use Cooper Black.
- `knowgap-lockup.svg`: horizontal symbol + wordmark for reuse outside the app.
- `knowgap-lockup-preview.png`: light-background preview of the horizontal lockup.
- `knowgap-app-icon.svg` / `.png`: charcoal tile and white mark for favicons and Apple touch icons.
- `Brand.tsx` / `Brand.module.css`: theme-aware UI mark and masked vector wordmark.
- Desktop PNG/ICO and backend ICO use the same book mark on a neutral tile.

Use the symbol alone at small sizes. Keep the center gap clear. Do not substitute
a system font for the outlined wordmark. The old `knowgap-logo-v1.png` is retained
only as a historical asset and is no longer referenced by the application.
