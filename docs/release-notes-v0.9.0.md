## KnowGap 0.9.0

- **新版界面**采用书页标志和暖纸色主题，更新了浅色与深色配色、阅读字体及桌面启动页。
- **首次使用**可以从一个主题开始，附上课件或讲义，也可以先逛演示空间。使用演示样例时，上手清单会区分示例和自己的学习进度。
- **学习卡片**更新了概念对比、步骤模拟、自测和交互图示的样式。卡片可以在回复生成时逐步显示，步骤模拟支持自动播放。
- **联网搜索**可在学习支线中使用，搜索结果会以卡片展示，并提供可打开的来源链接。
- **提示词管理**将智能体与学习卡片的提示词移入按用途整理的 YAML 文件，随桌面版一起打包。

Windows 10 / 11 用户可下载安装包，也可在 KnowGap 的「设置 → 通用 → 软件更新」检查更新。
