## KnowGap 1.0.4

- 安装时可以选数据文件夹：用安装包安装时新增「选择数据文件夹」一步，默认放在 D 盘（D:\KnowGap Data），和安装目录分开，升级、重装都不会动到它；以前保存在 C 盘的数据会在第一次启动时自动搬过去。用更新按钮升级的保持原来的位置，想换到 D 盘可以下载安装包重新安装一次。
- 资料上传上限从 20 MB 提高到 100 MB。
- AI 记得之前的对话：问「上个对话聊了什么」「4 小时前那段说了啥」，AI 能找到对应的对话并打开原文回答。
- Word 文档里的图片也会识别：架构图、截图、表格截图等交给识图模型转写，文字并回图片所在的位置（需要在「设置 → 模型接入」配置识图模型）。
- 文件卡片的提示更准确：正文都读到、只是图片没读时显示「图片未读」，不再显示让人误会的「没读到的内容」。
- 新增系统技能：读 PDF / Word / PPT / Excel，做 Word / PPT / Excel / PDF。AI 读、改、生成这些文件时会自动调用，可在「设置 → 技能」里查看。

Windows 10 / 11 用户可下载安装包，或点侧栏顶部的圆形更新图标升级。
