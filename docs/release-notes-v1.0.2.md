## KnowGap 1.0.2

- 点引用看原文：回答下方的引用条目、正文里的 [资料N] 角标都能点，原文在对话右侧打开并翻到引用的那一页，顶部附上引用摘录。资料已删除时会提示，不会报错。
- AI 会自己翻资料：一次检索不够时，AI 会换关键词再搜资料库，再按页读原文作答。学习空间里优先用本空间的资料，不会混入其他空间。
- 读图修复：用 ChatGPT 账号登录或 OpenCode Go 的模型时，发图片、扫描版 PDF 和课件图片现在都能正常识别。
- 排版细节：中英文之间自动留出间距、标点挤压更紧凑；可视化卡片里的文字跟随应用字体和字号设置；动画时长统一，「减少动画」设置对卡片同样生效。

Windows 10 / 11 用户可下载安装包，或点侧栏顶部的「更新」按钮升级。
