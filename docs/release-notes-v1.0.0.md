## KnowGap 1.0.0

**这是正式版。升级后第一次打开会清空旧版本的全部数据**，包括对话、学习空间、学习记忆、日程、资料，以及模型配置（含 API Key），之后重新进入首次设置。

- 不用登录了：改成本机档案，可以设置称呼和头像；首次启动两步完成——认识你、接入模型，然后和 AI 聊几句，它会把你在学什么、喜欢怎么讲记进长期记忆。
- 自动更新更省心：每小时检查一次，后台自动下载；下载好后侧栏顶部会出现「更新」按钮，点一下就重启安装。
- 记忆页重新设计：按「关于你 / 学习主题 / 环境与资料」列出，点进去看详情或删除；想改什么，在底部用一句话告诉 KnowGap。对话里的「学习记忆」抽屉也精简了。
- 对话右侧的提问导航：鼠标停在刻度上，会弹出这一问和回答开头的预览，点一下跳过去。
- 学习空间可以选图标。
- 随堂小测做完再问「为什么错」，AI 知道你选了哪个。

Windows 10 / 11 用户可下载安装包；已装旧版本的，在「设置 → 通用 → 软件更新」里升级到 1.0.0，之后的版本就用侧栏顶部的「更新」按钮。
