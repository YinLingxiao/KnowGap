## KnowGap 0.9.5

- 输入框新增六种回答模式：讲解、解题、练习、规划、研究、整理资料。选中后按对应方式回答，例如练习模式会出小测验；再点一次即取消。
- 移除斜杠命令，输入「/」不再弹出菜单；「@」引用 Skill 和文件保持不变。
- 学习空间的回答会区分「空间资料」和「通用资料」，两者冲突时以空间资料为准。
- 记忆按空间隔离：普通对话不再调用学习空间里的记忆，空间之间也互不混用。
- 主题切换按钮回到侧栏底部，桌面版也使用圆形扩散动画。
- 修复对话列表右侧「…」按钮点不开的问题。

Windows 10 / 11 用户可下载安装包，或在「设置 → 通用 → 软件更新」中检查更新。
