这一版改善了 AI 生成回复时的交互，并修复了学习卡片偶尔导致整页白屏的问题。v0.8.0 没有正式发布，它的内容都包含在这一版里：

新功能
- AI 回复时可以继续输入，按 Enter 加入待发送，当前回复结束后按顺序自动发出。待发送的消息可以修改、撤回，每个对话最多暂存 10 条
- 想换个方向时，输入新要求后点「停止并按新要求重答」，已经生成的内容会保留
- 刷新页面、切换对话或短暂断线后，正在生成的回复会自动接上，不会重新生成
- 往上翻阅读时不会再被拉回底部；选中文字时显示暂停，方便复制或追问，点「回到底部」恢复跟随

修复
- 对比卡片生成到一半时可能导致整页白屏。现在单张卡片出错只显示原文，不影响其他内容

变化
- 切换对话或刷新页面不再停止生成，回复会在后台继续；需要停止时请点停止按钮
- 完全退出程序会中断生成，重启后保留已经生成的正文；待发送的消息会暂停，需要手动点「继续发送」

说明
- 从这一版起，新版本由 GitHub 自动构建、检查并发布
- 安装包未签名，Windows 可能提示未知发布者
