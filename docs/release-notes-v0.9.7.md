## KnowGap 0.9.7

- 新增「复习备考」模式：跳过零基础铺垫，直击高频考点和易错陷阱，以课件里的重点和例题为准，结尾附一道速测，没掌握的点用缺口卡列出。
- 问资料库里某份课件讲了什么时，会按页读正文再回答，不再只凭目录页拼框架，也不会把课件里的思考题原样丢回给你。
- 六种回答模式的提示词重新整理：解题时你要完整答案或连续卡住就直接给解析，练习时直接出题，规划时信息不全也先给一版可执行方案，研究模式在普通对话里也能联网查资料。
- 模式选择换了样式：首页在输入框下方排成一行，对话中收进工具栏的「模式」下拉。

Windows 10 / 11 用户可下载安装包，或在「设置 → 通用 → 软件更新」中检查更新。
