学习空间的主线更清爽了，这一版也做了大幅精简，并升级了桌面运行环境：

- 主线不再刷屏：支线每聊一轮不再往主线写进展，支线在主线里只占一张卡片，状态实时更新
- 协调者会跟进支线：支线解决或任务失败后，协调者会读取汇报，只在需要时才说话，比如说明失败原因、建议下一步
- 资料库预览：修复 Excel 解析的安全问题
- 桌面运行环境：升级 Electron，修复一批安全问题
- 合并提示：「已合并到主线」不再跟着切到别的学习空间

移除的功能
- 模拟复试 `/viva`
- 闪回：不再自动往日程里生成复习任务。未解决的误区改为显示在首页「待巩固的易错点」

升级须知
- 升级后第一次打开日程时，所有历史闪回任务会被删除，包括已完成的记录，无法恢复。你挂在闪回任务下的手动子任务会保留，并变成普通任务。如需留底，升级前请备份数据目录 `%APPDATA%\knowgap-desktop`
