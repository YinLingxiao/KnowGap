这一版把普通对话（平行对话）改成了通用助手：问什么就答什么，不再套用学习空间里的带练流程。学习空间的主线和支线不受影响。

变化
- 普通对话里讲题或问问题，会直接给出思路、关键步骤和答案，篇幅跟着问题走，不再自动出题、列计划或等你作答
- 说「直接告诉我」「只要答案」「简单说」时，答完就停
- 其他问题答完后，可能在结尾提一个延伸方向（相关方法、同类题、背后原理等），只问一个，不理它也没关系
- 能用可交互卡片讲清楚的内容（结构、过程、推导、对比、参数变化），会尽量用卡片呈现
- 普通对话里不再出现「考考我」之类的灰字追问；多步任务仍会显示计划条
- 带附件的普通对话按你的要求直接处理文件，不再先引导

说明
- 普通对话仍会记住你的偏好和学习情况，用来调整讲法
- 安装包未签名，Windows 可能提示未知发布者
