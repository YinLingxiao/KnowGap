## KnowGap 1.0.1

- 新增 OpenCode Go 模型预设：在「设置 → 模型接入 → 添加服务商」里选 OpenCode Go，填上 OpenCode 控制台的 API Key 即可。KnowGap 会自动带上 OpenCode 要求的会话请求头，不再出现 `missing_session_id` 错误。
- 1.0.0 的数据清空只会在第一次打开 1.0.x 时进行一次；已经是 1.0.0 的用户升级到 1.0.1 不会再清空。

Windows 10 / 11 用户可下载安装包，或点侧栏顶部的「更新」按钮升级；还在 0.9.x 的，在「设置 → 通用 → 软件更新」里升级。
