这一版重点升级了对话里的学习卡片：边生成边出现，作答会记进学习记录，还能直接画图和算数：

- 卡片边生成边显示：推演、对比、测验卡在回复生成过程中就逐步出现，写完才能点；生成失败会提示并可查看原文
- 随堂微测：先选再提交，由服务端判分；刷新后作答结果还在；答错的选项会记入对应误区，答对能推进学习计划里等你作答的步骤
- 缺口卡：再次碰到以前记录过的误区时，卡片会列出证据，可以「做一道题验证」或标记「这个判断不准确」
- 图示卡：AI 可以直接画二叉树、结构图、占比条、带滑块的计算器等，在隔离环境里运行，不联网
- 提问导航：对话右侧一列刻度，悬停展开提问列表，点一下跳过去（平行对话；主线在关闭右侧面板时；支线在全屏时）
- 支线全屏和退出全屏有过渡动画
- 卡片更好读：正文字号加大、去掉左上角类型标签、生成中按卡片类型显示骨架，推演卡支持方向键切步骤
- 界面：中英文统一显示 KnowGap；中文改用系统字体（微软雅黑 / 苹方），小字号更清晰

修复
- 学习空间里主线和支线同时打开时，点卡片上的追问会同时填进两个输入框
- 卡片里的列表多出圆点和缩进

移除的功能
- 参数实验卡（滑块不会真正计算）。旧对话里的这类卡片会显示「这种卡片已不再支持」，计算类需求改由图示卡完成

说明
- 升级前生成的微测题仍在本地判分，不会写入学习记录
- 安装包未签名，Windows 可能提示未知发布者
