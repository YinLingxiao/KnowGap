## 六、排错 3：全量 3 条 drill e2e 失败的真实根因

### 现象

B3 全量曾出现 `4 failed, 1163 passed`：1 条已知 Windows PowerShell 环境失败 + 3 条 drill e2e。drill 文件单跑有时 `4 passed`，负载下失败项在三条之间轮换，失败点都是 `streaming.py:70` 的 15 秒 `asyncio.wait_for` 超时。

### 定位

Python 3.10 里：

```text
asyncio.TimeoutError is builtin TimeoutError -> False
MRO: asyncio.TimeoutError -> Exception -> BaseException
```

而 `asyncio.wait_for` 抛的是 `asyncio.TimeoutError`。两处 `except TimeoutError` 在 3.10 上捕获不到：

- `app/chat/streaming.py:71`：SSE 心跳 `wait_for(changed.wait(), timeout=15)`，本意超时后 `yield ": keep-alive\n\n"`；异常逃逸导致超过 15 秒没事件的回合断流。
- `app/chat/service.py:338`：工具审批 `wait_for(future, 600)`，本意超时 `return False`；3.10 上会抛错。

### 修复

- 两处改为 `except asyncio.TimeoutError:`，3.10 与 3.11+ 都正确。
- 魔法数字提常量：`KEEPALIVE_SECONDS = 15`、`APPROVAL_TIMEOUT_SECONDS = 600`；`read()` 和审批使用常量。
- 数值本身不变，行为不变；未改 drill 测试，未改 B3 的 mode 逻辑。

### 验证

