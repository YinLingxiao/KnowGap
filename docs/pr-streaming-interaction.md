# 标题

feat: 改善流式交互并接通 Windows 自动发布

# 说明

生成回复时可以继续输入，编辑或撤回待发送消息，也可以停止当前回复并立即按新要求重答。向上阅读和选中文字时保持当前位置，切换页面或短暂断线后重新接回原生成任务。已收到的内容持久保存，重连不会重复请求模型或重跑工具。

修复对比卡片尚未写出字段时导致的白屏，为学习卡片增加原文降级。保留原有原图批注、电路网表确认、工具审批和模型接入流程。

桌面版本升为 0.8.0。PR 运行 Windows 测试、打包及冻结后端检查；合并到官方 main 后，仅当版本高于最新正式版且所有验证通过，才自动创建标签并发布完整安装包、blockmap 和 latest.yml。草稿上传完整后才公开，已发布版本不可覆盖。

# 验证与限制

本地验证：前端 250 项、后端完整回归 1104 项、桌面及发布 29 项全部通过。生产构建、冻结程序检查和自动更新文件校验通过。Computer Use 在独立模拟数据中确认生成中追加、待发送修改、接续执行、停止后保留正文和暂停队列、刷新接回原任务、向上阅读及卡片显示。

- 前端包含对卡片每个 JSON 前缀的真实公式渲染回归，以及事件游标、排队、立即修改要求、旧回调隔离和平滑输出测试。
- 后端包含独立订阅者、断线后继续生成、停止目标、队列、进程恢复和断点事件段落回归。
- 桌面包含更新策略、安装前退出顺序、产物哈希、版本、草稿恢复和 PR 发布权限回归。
- `scripts/smoke-desktop.py` 使用临时数据库检查实际打包后端、页面资源、待发送接口和重启持久化，不发送模型请求。
- 进程完全退出会中断供应商生成，恢复部分正文并暂停待发送队列；此实现使用单个后台服务进程。
- 首次 GitHub 工作流和真实公开更新，需要合并后检查 Actions、Release，再由带更新器的旧安装版验证。仓库须允许发布任务的 contents: write 权限。

使用方式见 `docs/streaming-interaction.md`，合并后发布流程及失败恢复见 `docs/desktop-release-automation.md`。
