# AI 学习产品调研：诊断结果呈现 & 提示机制

> 黑客松 AI+学习赛道 · 交互与界面任务调研产出
> 调研日期：2026-10-15
> 说明：以下内容基于产品公开资料、官方说明与历史版本体验整理，落地设计前建议实机试玩核对最新版本。

---

## 一、调研目的

为团队产品的 3 个核心页面线框图（诊断结果页 / 学习答题页 / 进度页）提供设计参考，重点回答两个问题：

1. 主流 AI 学习产品**怎么呈现诊断结果**（学情报告、能力画像、薄弱点）
2. 主流 AI 学习产品**怎么给提示**（直接给答案 vs 分步引导 vs 对话追问）

## 二、观察框架

每款产品按固定维度记录，保证可横向对比：

- **诊断呈现**：总览形式 / 薄弱点可视化 / 数据颗粒度 / 下一步 CTA / 情绪处理
- **提示机制**：是否分步 / 呈现位置 / 引导方式（讲解 vs 反问）/ 答案门槛

## 三、产品逐个分析

### 1. Duolingo（语言学习，全球标杆）

- **诊断呈现**：定级测试（Placement Test）定段后直接跳到对应单元，弱化「报告」概念，把诊断结果「藏」进学习路径里；错题按题型（听力/词汇/语法）归入练习中心；掌握度用进度条 + 单元皇冠等级表达
- **提示机制**：答错立即显示正确答案 + 一句规则说明；无分步提示；错题会在后续关卡自动复现（间隔重复）
- **可借鉴**：进度可视化极强（Streak 连续打卡、进度环）；反馈即时、情绪永远正向；诊断≠报告页，也可以是路径本身

### 2. Khanmigo / Khan Academy（K12 全科 AI 导师）

- **诊断呈现**：Course Challenge / Unit Test 后按技能点（Skill）列出掌握度标签：Attempted / Familiar / Proficient / Mastered，颜色区分，可点击直达对应练习
- **提示机制**：**脚手架式提示（Scaffolding）的标杆**——Socratic 对话式引导，反问「你觉得第一步该做什么？」，设计上拒绝直接给答案；教师端可查看完整对话记录
- **可借鉴**：掌握度标签比冷冰冰的分数更友好；「反问引导」比「直接讲解」更有教育价值，答辩时是很好的理念背书

### 3. Photomath（拍照解题，已被 Google 收购）

- **诊断呈现**：无整体学情诊断，停留在单题维度
- **提示机制**：分步解析（Step-by-step），每一步可展开「为什么这样做」的动画讲解；步骤免费、原理深讲付费——把「渐进式披露」做成了商业模式
- **可借鉴**：**Progressive Disclosure（渐进式披露）**的教科书案例：答案折叠，用户主动逐层展开

### 4. Gauth（字节出海拍照解题）

- **诊断呈现**：拍题 → 识别结果卡片（题目 + 答案 + 分步解析）+ 相似题推荐，形成「以题带点」的轻诊断
- **提示机制**：结果卡下方直接接 AI 对话框可追问；AI 答不了时真人导师兜底
- **可借鉴**：「识别卡片 + 追问对话」的轻交互非常适合手机端；一屏内完成「看答案→问为什么」闭环

### 5. 豆包爱学（字节国内 K12 AI 学习）

- **诊断呈现**：AI 学情报告结构完整——知识点掌握度雷达图/柱状图 → 薄弱知识点列表 → 自动生成个性化练习，三段式一气呵成
- **提示机制**：AI 讲题对话支持无限追问；**错因分析**是亮点——不只给答案，而是指出「你错在第几步、为什么错」
- **可借鉴**：诊断报告「总览→薄弱点→推荐路径」的三段式结构，是我们诊断结果页最直接的参考原型

### 6. 作业帮 / 猿辅导（国内 K12 传统强厂）

- **诊断呈现**：知识点图谱（树状图，红/黄/绿标注掌握状态）+ 能力雷达图 + 预测分；颗粒度细到具体考点（如「一元二次方程-求根公式」）
- **提示机制**：举一反三推荐同类题；视频讲解兜底；提示相对「重内容轻交互」
- **可借鉴**：Knowledge Graph（知识点地图）可视化在答辩展示时视觉冲击力强

|---|---|---|---|---|---|

| Khanmigo | 掌握度标签列表 | 标签颜色区分 | 技能点级 | 点击技能点直达练习 | 对话反问，不给答案 |
| Photomath | 无 | 无 | 单题级 | 相似题 | 分步展开，逐层披露 |

| 作业帮/猿辅导 | 雷达图+预测分 | 知识点图谱红黄绿 | 考点级 | 推荐同类题 | 视频讲解+同类题 |

## 五、核心结论（对线框图的设计启示）

1. **诊断报告三段式**：总览（标签/雷达图）→ 薄弱点列表（可点击）→ 个性化推荐 CTA，这是被验证最多的结构
2. **提示要分步、渐进披露，最后才给答案**：提示→思路→解析→答案，每步用户主动触发；最好支持对话追问
3. **掌握度标签优于分数**：「待巩固」比「58 分」更能保护学习动机
4. **手机端硬约束**：单列布局；提示放底部弹层（Bottom Sheet）；主 CTA 用大按钮固定底部；雷达图在窄屏上最多 6 个维度
5. **情绪设计**：鼓励性文案 + 成长型表述（「再练 2 题就能点亮这个知识点」），答错不惩罚
6. **闭环意识**：诊断不是终点，报告页必须有明确的「立即开始学」出口，诊断→学习→再诊断形成循环

## 六、UI 术语速查（答辩可直接用）

| 术语 | 中文 | 用在我们产品的哪里 |
|---|---|---|
| Wireframe | 线框图 | 本次交付物本身 |
| Onboarding | 新手引导 | 首次进入的定级测评流程 |

| Bottom Sheet | 底部弹层 | 答题页的 AI 提示面板 |

| Scaffolding | 脚手架式提示 | 反问引导代替直接给答案 |

| Skeleton Screen | 骨架屏 | AI 生成报告时的加载态 |
| Streak | 连续打卡 | 进度页的激励模块 |
